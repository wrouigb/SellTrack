# Database schema

PostgreSQL 16. Migrations in `migrations/` are the source of truth, and a test checks that this page covers every table and column.

**Conventions**
- Money is `numeric(12,2)`, in AUD, and never a float. Checks reject negative amounts where they make no sense, and also `NaN`, which Postgres would otherwise treat as larger than any number.
- Times are `timestamptz`, stored in UTC.
- Almost everything belongs to an account through `user_id`, and goes when the account does. Composite foreign keys on `(user_id, id)` make it impossible for a row to point at another account's person or settlement.
- A row with `settlement_id` empty is in the current period. Settling up stamps it, and undoing clears it.

|---|---|

## Running the site

### audit_logs
Security-related actions. The app's database role can only add to this table, and it's never trimmed. It outlives accounts, so it holds no names of people or amounts of money.

| Column | Notes |
|---|---|
| `id` | |
| `actor_id` | Who did it. Becomes empty if their account is deleted |
| `action` | Such as `admin.password_reset` |
| `target_type`, `target_id` | What it was done to |
| `ip`, `user_agent` | |
| `request_id` | Matches the app's logs |
| `metadata` | `jsonb`. Admin pages only show the fields listed for each action |
| `created_at` | |

### feature_flags
| Column | Notes |
|---|---|
| `id` | |
| `key` | Unique |
| `description` | |
| `enabled` | Off means off for everyone, including the allowlist |
| `rollout_pct` | 0 to 100. Raising it only ever adds people |

| `created_at`, `updated_at` | |
